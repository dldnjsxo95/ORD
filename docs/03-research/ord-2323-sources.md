## 1. 버전 확인

- "2.323" 은 원작자 버전이 아니라 **원랜디R(ORDR) 리부트 시즌 2** 의 2.323 이다. 맵 파일명은 `ORDR_S2_2.323[C].w3x`.
- 원작자 버전은 11.089 에서 2023-09 에 개발 중단(IP 문제). 이후 ORDR 팀이 팬 유지보수. 나무위키 유닛 설명은 대부분 9.x~11.0xx 기준이라 **2.323 데이터로 쓰면 안 된다**.
- 2.32x 패치 흐름(디시 패치노트 검색 요약, 게시일 미확인): 2.320 이세계 모드 개인미션 추가 / 2.321 일부 물리 유닛 약화 버그 수정 / 2.322 VIP 칭호 제한등급 오라 / 2.323 시스템 최적화, 항법 노드 신규 유닛, 가반(불멸) 팔십효수·팔천효수 절대쿨타임 변경, 칭호 왜곡등급 날개 이펙트, 패왕의길 항법 버그 수정, 징베(초월) 귀신기와정권 400만→440만.
- 2026-10 중순 ordsearch.net 클리어 기록 댓글에 "2.323 ver" 표기 → 현재 플레이 버전으로 맞다.
- 공식 배포 채널은 ORDR 팀 디스코드(ordr.co.kr, 현재 DNS 미해석). m16tool.xyz CDN 에는 S2 2.004(2025-08-08, 168MB)까지만 있고 2.323 은 없음.

## 4. 용어 (나무위키 기준, 2.323 수치는 미검증)

- **물딜**: 적 방어력에 깎이는 물리 피해 빌드. 깎(방깎) 디버프를 쌓아 방어력을 크게 낮춰야 한다.
- **마딜**: 방어력을 무시하는 마법 피해 빌드. 단일(단일 대상 % 피해), 끝딜(마무리 피해), 마방깎·도킹(마법 피해 증폭)에 의존.
- **깎(깎이)**: 방어력 감소 디버프. 같은 이름의 스킬은 중첩되지 않고 낮은 쪽이 적용.
- **방무뎀**: 방어 무시 평타 피해(제3의 선택지).

## 5. 관찰된 유닛 데이터 구조 (tmo.gg 문서 2건을 사람이 확인한 범위)

조합 DB 스키마를 넓힐 때 참고. 값은 예시.

```
등급(level): "안흔함"
공격력(damage): "127 - 133"
조합 재료(recipe): [{name:"몽키.D.루피"}, {name:"해군 총병"}]   ← 수량 없이 재료 목록
스킬(skills): [{title:"이글이글 열매 :: Lv.1", details:[{label:"기본 효과", text:"공격 시 10% 확률로 단일 적 200 물리 데미지"}]}]
갱신일(updatedText): "2026.08.23 수정"
```

→ 현재 ord-core 스키마에 **스킬, 공격력 범위, 피해 유형(물리/마법), 획득 경로 분류, 재료 아이템** 이 빠져 있다. 맵 데이터를 보고 확정한다.
