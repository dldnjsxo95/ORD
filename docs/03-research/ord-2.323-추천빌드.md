## 1. 클리어 공식 (악몽)

| 딜 타입 | 공식 | 우선순위 |
|---|---|---|
| 물딜 | 상위딜러 1 + 풀깍 180~210 + 스턴 1.5 + 이감 102% + 보스딜러 1 | 깍 = 0.5스턴 > 이감 > 스턴. 니카·거프는 버프만 충분하면 120깍부터 |
| 마딜 | 상위딜러 2 + 토키(전설) + 스턴 1.5 + 이감 102% + 광보잡 1 + 마방깍·마뎀증 | 광보잡은 상위딜러로 점사하면 딜로스 → 따로 하나(루나메·아카히든·네코, 없으면 베이비5 변이 1~2) |

물딜 상위딜러 3유형 (악몽 물딜 공략)
- 공증딜러: 기본공격 % 스킬·스플래시·크리티컬. 예 카타쿠리 제한, 가반 불멸, 거프 불멸, 레일리 불멸. 공증·공속·체젠 버퍼와 함께.
- 암브딜러: 아머브레이크 중첩에 추가 효과. 예 징베 초월, 킹 제한, 후지토라 초월, 료쿠규 초월. 암브 유닛 1기를 15~30깍(최대 20~40)으로 환산해 풀깍을 잡는다.
- 스킬딜러: 물리 스킬 데미지가 정해져 있어 공속 빼고는 깍만 본다. 예 조로(염왕) 초월, 바질호킨스 초월, 흰수염 불멸.

물딜 보스딜러: 레드포스호 · 킬러 히든 · 히바리 전설 · 검호(물약) 중 하나. 스턴은 바르토로메오·시키 전설·봉쿠레·이완코브로. 이감은 메인 딜러 자체 이감 + 스모커 50 / 모비딕호 40 / 사보 히든 20 + 짤이감.

마딜 세트
- 에제 세트 = 에넬 제한 + 토키 전설 + 쿠마 세라핌(S-베어). 깡딜 조합 클리어 키. 마방깍·마뎀증은 후지토라 전설·쿠마 물약·방주맥심·에넬로.
- 공증 세트 = 네코마무시·쵸파 몬스터포인트 같은 공증 + 토키.
- 스킬 색: 현재체력 % = 단일 컨트롤 필요, 전체체력 % = 끝딜, 깡 마법 = 마방깍·마뎀증 영향, 폭발 = 폭발 증폭, 방무 = 공증 영향, 고정 = 고정.
